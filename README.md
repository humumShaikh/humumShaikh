## Selected Projects

**AXI4-Lite to SPI Bridge (FPGA)**  
Design and implementation of a Verilog-based bridge translating AXI4-Lite transactions into SPI transfers. Emphasis on protocol correctness, FSM-driven control, and clean timing behavior suitable for SoC-style integration.

**Ghost_RF**  
An experimental project exploring wireless signal interference and RF transmission behavior. Focused on practical understanding of spectrum usage, signal disruption, and RF system fundamentals.

**PSPI — Parity Serial Peripheral Interface**  
A custom-designed serial communication protocol incorporating parity for data integrity. Implemented at RTL level with attention to framing, error detection, and protocol robustness.
